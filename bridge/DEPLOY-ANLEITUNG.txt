========================================================================
SCHRITT 1: TOKEN ERSTELLEN
========================================================================

Diese Adresse im Browser oeffnen:

    https://supabase.com/dashboard/account/tokens

Falls nicht angemeldet, erst einloggen. Die Seite heisst
"Access Tokens" und liegt unter Account Settings.

Dort:
  a) Rechts oben auf den gruenen Knopf  "Generate new token"
  b) Als Namen eintragen:   orion-deploy
  c) Auf  "Generate token"  klicken
  d) Es erscheint EINMALIG eine Zeichenkette, die mit  sbp_  anfaengt.
     Auf das Kopier-Symbol daneben klicken.

WICHTIG: Der Token wird nur dieses eine Mal angezeigt. Schliessen Sie
das Fenster, ist er weg und Sie machen einen neuen. Das ist kein
Problem, dauert 30 Sekunden.

Nicht abspeichern, nicht in den Chat schreiben, nicht per Mail
schicken. Er hat vollen Zugriff auf Ihr GESAMTES Supabase-Konto,
nicht nur auf Orion.


========================================================================
SCHRITT 2: DEPLOYEN
========================================================================

  a) Windows-Taste druecken
  b) cmd tippen, Enter
  c) Die folgende Zeile hineinkopieren, aber IHR_TOKEN durch den
     kopierten Wert ersetzen:

cd C:\Users\Home\orion-panel-pro && set "SUPABASE_ACCESS_TOKEN=IHR_TOKEN" && npx --yes supabase@latest functions deploy orion-lauf --project-ref noexklrgtqveiclijdwp --no-verify-jwt

   ACHTUNG, die Anfuehrungszeichen um SUPABASE_ACCESS_TOKEN=... sind
   PFLICHT. Ohne sie haengt cmd ein Leerzeichen an den Token an
   (gemessen: Laenge 7 statt 6), und Supabase lehnt ihn ab. Genau
   daran ist der erste Versuch am 19.8. gescheitert.


  d) Enter. Es dauert etwa eine Minute.

RICHTIG gelaufen ist es, wenn am Ende steht:

    Deployed Functions on project noexklrgtqveiclijdwp

Das "set" gilt nur in diesem einen Fenster. Schliessen Sie es, ist der
Token aus dem Speicher.

========================================================================
