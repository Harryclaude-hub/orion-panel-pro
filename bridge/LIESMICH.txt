AUF EINEM ANDEREN PC EINRICHTEN
-------------------------------
1. Ordner entpacken, 2. bridge-config.json hineinkopieren,
3. Doppelklick auf Bridge-start.cmd, 4. Fenster offen lassen.

Voraussetzung: Node muss auf dem Rechner sein (nodejs.org, LTS).
Die Startdatei sagt es dir, falls es fehlt.

SPORTARTEN-SCHALTER (seit Build 21)
-----------------------------------
In bridge-config.json darf ein Feld "sportarten" stehen. Damit kannst
du je Sportart drei Dinge einstellen — alles freiwillig, fehlt das
Feld, läuft alles wie bisher:

  aktiv           false nimmt die Sportart ganz aus der Rotation
  fensterStunden  wie weit DIESE Sportart vorausschaut (höchstens das
                  globale Fenster; der Server nimmt ohnehin nur 72 h)
  anteil          wie oft sie je Rotationszyklus drankommt (Standard 1)

Beispiel (in bridge-config.json, auf gleicher Ebene wie bridgeUrl):

  "sportarten": {
    "tennis": { "aktiv": false },
    "esport": { "anteil": 2, "fensterStunden": 24 }
  }

Gültige Schlüssel: fussball, tennis, basketball, baseball, football,
eishockey, cricket, boxen, mma, motorsport, esport.

Beim Start zeigt die Bridge die wirksame Einstellung vollständig an,
samt Zeile "ABGESCHALTET: …". Ein vertippter Schlüssel oder ein
unbekanntes Feld wird LAUT als WARNUNG gemeldet, nie still verschluckt.
Nach jeder Änderung an der Zugangsdatei: Aufgabe neu starten
(Aufgabenplanung -> "Orion Bridge" -> Beenden, dann Ausführen).


WENN ETWAS NICHT GEHT
---------------------
„Anmeldung fehlgeschlagen"   → zuerst den Benutzernamen in
                               bridge-config.json prüfen (häufigster Fall)
„Blockiert (HTML statt Daten)" → VPN aus; Betfair sperrt Rechenzentren
Fenster schließt sofort       → Node fehlt (nodejs.org, LTS)
Panel zeigt „Betfair-Daten sind X alt" → die Bridge läuft nicht oder
                               der Rechner schläft. Standby aus:
                               Einmalig-Standby-abschalten.cmd
